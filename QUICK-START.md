## 💡 **Quick Tips:**

### **To Customize:**
1. **Colors:** Edit `:root` variables in `styles.css`
2. **Content:** Edit HTML files directly
3. **Animation Speed:** Edit `setTimeout` in `script.js` (line ~8)
4. **Company Info:** Update footer in all HTML files

### **To Add Logo:**
1. Save logo as `logo.png` in website folder
2. Replace `<h1>TeleSpace.io</h1>` with `<img src="logo.png">`

### **To Change Animation:**
1. Open `styles.css`
2. Find `/* SPACE-THEMED PRELOADER */` section
3. Modify colors, sizes, speeds
